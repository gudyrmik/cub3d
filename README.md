# cub3d

Collaborative repository for the 42 cub3D project.

## Team

- Team lead and reviewer: [@gudyrmik](https://github.com/gudyrmik)
- Developer: [@alnurn](https://github.com/alnurn)

Work is tracked in [Issues](https://github.com/gudyrmik/cub3d/issues) and submitted through [Pull Requests](https://github.com/gudyrmik/cub3d/pulls). The `main` branch is reserved for accepted changes.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before starting a task.

## Requirements

The official cub3D subject provided to the team and the applicable 42 Norm are the sources of truth. Implementation requirements and checks will be defined from those materials, not assumed in advance.
